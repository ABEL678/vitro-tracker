ПАТЧ 08 — финальная ревизия вкладки «План выдачи» (vitro/ui/plan.py + vitro/plan_xlsx.py)
=========================================================================================

СОСТАВ
------
  vitro/ui/plan.py        — вкладка «План выдачи комплектов», новая архитектура;
  vitro/plan_xlsx.py      — парсеры ведомостей + двухлистовая Excel-выгрузка;
  scripts/test_patch08.py — автотесты (35 проверок), запуск:
                            python scripts/test_patch08.py
  ../patches/08-plan-final-ui.patch — тот же патч в формате git apply.

ЧТО ИЗМЕНИЛОСЬ (5 пунктов финальной ревизии)
--------------------------------------------
1. Блок «Вводные данные»: кнопки скачивания шаблонов Excel удалены —
   остаются только загрузка реальных ведомостей и очистка плана.

2. Период «с / по» (st.date_input, ключи plan_date_from / plan_date_to)
   перенесён из низа вкладки наверх — сразу под блоком фильтров, до
   сводной таблицы. Период применяется к ОБЕИМ детальным таблицам:
   у комплекта — срок готовности, у листа — плановая дата (если у листа
   даты нет — срок комплекта). Сводная таблица и бублики от периода
   не зависят.

3. Сводная таблица сгруппирована «Дисциплина → Раздел» (строки-заголовки
   «📁 01_АР · Подземная часть», внутри — комплекты группы). Колонок
   шесть: Шифр комплекта, Наименование комплекта, Общий статус,
   Листов в Витро, Листов (план), Срок готовности (редактируемый).
   Колонок «Дисциплина»/«Раздел» в таблице больше нет. Внизу — строка
   «ИТОГО»: суммы листов Витро/план + число комплектов. Строки «📁…» и
   «ИТОГО» в сохранение сроков не попадают.

4. Детальная таблица разделена на две:
   А) «Детальный план по комплектам» — Комплект(ы), Наименование
      комплекта, Плановая дата (срок готовности), Статус комплекта;
   Б) «Детальный план по листам комплекта» — Дисциплина, Раздел,
      Комплект(ы), Номер листа, Наименование листа, Плановая дата,
      Фактическая дата (дата статуса листа в Витро, если загружен).
   Все фильтры и период действуют на обе таблицы.

5. Кнопка «📥 Выгрузить в Excel: листы «Комплекты» и «Листы»» формирует
   файл из листов «Комплекты» (таблица А), «Листы» (таблица Б) и
   «Параметры выгрузки» (период, дата формирования, объёмы) — с учётом
   текущих фильтров и выбранного периода; даты в формате ДД.ММ.ГГГГ.

ПРИМЕНЕНИЕ — вариант 1 (копированием, рекомендую)
-------------------------------------------------
  files-08/vitro/ui/plan.py    ->  vitro\ui\plan.py
  files-08/vitro/plan_xlsx.py  ->  vitro\plan_xlsx.py
Улучшения патча 07 (дисциплина из шифра, раздел из названия, без
авто-rerun после сохранения сроков) уже включены в эти файлы —
патч 07 отдельно применять не нужно.

ПРИМЕНЕНИЕ — вариант 2 (git apply)
----------------------------------
  git apply --check patches/08-plan-final-ui.patch
  git apply patches/08-plan-final-ui.patch
Патч построен на состоянии «после патчей 04–06». Если патч 07 уже
применён и git apply --check ругается на plan.py:
  git apply --3way patches/08-plan-final-ui.patch
либо используйте вариант 1 (замена файлов целиком).

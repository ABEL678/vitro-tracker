# Vitro-tracker

Веб-приложение для работы с замечаниями к рабочей документации (РД) из Витрокад.

**Заказчик:** АТП ТЛП
**Стек:** Python 3.14 · Streamlit · SQLite · Plotly · openpyxl · reportlab

## Что делает

- Синхронизирует замечания, листы и комплекты из SharePoint (Витрокад) в локальную БД SQLite.
- Позволяет 10 специалистам категоризовать замечания (4 категории) с оптимистичной блокировкой.
- Даёт аналитику: обзор, комплекты, авторы, зависшие, отстающие, ревизии, динамика, поиск, экспорт.
- Выгружает данные в Excel (форматированные отчёты) и PDF.

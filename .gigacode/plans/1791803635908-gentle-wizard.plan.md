# План: Улучшение оформления Excel-выгрузки

## Файл для изменения

- `vitro/ui/summary.py` — функция `_export_summary_to_excel`

## Требования

1. **Шапка:** бледные цвета, чёрный шрифт, убрать эмодзи-кружки из заголовков
2. **Автоширина:** убрать, колонки C-H одинаковой ширины (12)
3. **Колонка B:** перенос строк (wrap text)

## Изменения

### 1. Бледные цвета заголовков

| Колонка | Название | Бледный цвет |
|---------|----------|-------------|
| D | Новое | #D6E4F0 (бледно-синий) |
| E | Не принято | #FCE4E4 (бледно-красный) |
| F | К обсуждению | #FFF2CC (бледно-жёлтый) |
| G | Принято в работу | #D0ECE7 (бледно-бирюзовый) |
| H | Выполнено | #D9EAD3 (бледно-зелёный) |
| Остальные | — | #D6E4F0 (бледно-синий) |

### 2. Убрать эмодзи из заголовков

При записи в Excel очищать заголовки от эмодзи:
```python
clean_name = cell.value
if isinstance(clean_name, str):
    clean_name = re.sub(r'[\U0001F300-\U0001F9FF]', '', clean_name).strip()
    cell.value = clean_name
```

### 3. Фиксированная ширина колонок C-H = 12

Убрать автоширину. Установить:
- Колонка A: 20 (шифр/код)
- Колонка B: 50 (наименование, с wrap)
- Колонки C-H: 12 (числовые)
- Остальные: автоширина

### 4. Перенос строк в колонке B

```python
from openpyxl.styles import Alignment
ws.cell(row=r, column=2).alignment = Alignment(wrapText=True)
```

## Полный код `_export_summary_to_excel`

```python
import re

def _export_summary_to_excel(df: pd.DataFrame, group_label: str, level: str) -> bytes:
    """Формирует красиво оформленный XLSX с бледными цветами и переносом строк."""
    buf = io.BytesIO()

    with pd.ExcelWriter(buf, engine="openpyxl") as writer:
        df.to_excel(writer, index=False, sheet_name=group_label)
        ws = writer.sheets[group_label]

        # --- Бледные цвета заголовков ---
        COLOR_HEADER_NEW = "D6E4F0"        # бледно-синий
        COLOR_HEADER_REJECTED = "FCE4E4"   # бледно-красный
        COLOR_HEADER_DISCUSSION = "FFF2CC" # бледно-жёлтый
        COLOR_HEADER_IN_WORK = "D0ECE7"    # бледно-бирюзовый
        COLOR_HEADER_DONE = "D9EAD3"       # бледно-зелёный
        COLOR_HEADER_OTHER = "D6E4F0"      # бледно-синий
        COLOR_TOTAL_ROW = "F0F0F0"         # серый для ИТОГО
        COLOR_BLACK = "000000"             # чёрный текст

        # --- Фиксированная ширина колонок ---
        ws.column_dimensions["A"].width = 20
        ws.column_dimensions["B"].width = 50
        ws.column_dimensions["C"].width = 12
        ws.column_dimensions["D"].width = 12
        ws.column_dimensions["E"].width = 12
        ws.column_dimensions["F"].width = 12
        ws.column_dimensions["G"].width = 12
        ws.column_dimensions["H"].width = 12

        # --- Границы на всю таблицу ---
        from openpyxl.styles import Border, Side
        thin_border = Border(
            left=Side(style='thin'),
            right=Side(style='thin'),
            top=Side(style='thin'),
            bottom=Side(style='thin'),
        )
        last_row = ws.max_row
        last_col = ws.max_column
        for r in range(1, last_row + 1):
            for c in range(1, last_col + 1):
                ws.cell(row=r, column=c).border = thin_border

        # --- Заголовки: убрать эмодзи, бледный цвет, чёрный текст ---
        from openpyxl.styles import PatternFill, Font, Alignment
        header_fill_map = {
            "Новое": COLOR_HEADER_NEW,
            "Не принято": COLOR_HEADER_REJECTED,
            "К обсуждению": COLOR_HEADER_DISCUSSION,
            "Принято в работу": COLOR_HEADER_IN_WORK,
            "Выполнено": COLOR_HEADER_DONE,
        }

        for c in range(1, last_col + 1):
            cell = ws.cell(row=1, column=c)

            # Убрать эмодзи из заголовка
            if isinstance(cell.value, str):
                clean_name = re.sub(r'[\U0001F300-\U0001F9FF]', '', cell.value).strip()
                cell.value = clean_name

            # Определяем цвет заголовка
            col_name = str(cell.value)
            fill_color = None
            for key, color in header_fill_map.items():
                if key in col_name:
                    fill_color = color
                    break

            if fill_color:
                cell.fill = PatternFill(start_color=fill_color, end_color=fill_color, fill_type="solid")
                cell.font = Font(bold=True, color=COLOR_BLACK)
                cell.alignment = Alignment(horizontal='center', vertical='center', wrapText=True)
            else:
                cell.fill = PatternFill(start_color=COLOR_HEADER_OTHER, end_color=COLOR_HEADER_OTHER, fill_type="solid")
                cell.font = Font(bold=True, color=COLOR_BLACK)
                cell.alignment = Alignment(horizontal='center', vertical='center', wrapText=True)

        # --- Перенос строк в колонке B (наименование) ---
        for r in range(2, last_row + 1):
            cell = ws.cell(row=r, column=2)
            cell.alignment = Alignment(wrapText=True)

        # --- Выделение строки ИТОГО (последняя строка) ---
        total_fill = PatternFill(start_color=COLOR_TOTAL_ROW, end_color=COLOR_TOTAL_ROW, fill_type="solid")
        for c in range(1, last_col + 1):
            cell = ws.cell(row=last_row, column=c)
            cell.fill = total_fill
            cell.font = Font(bold=True)

        # --- Автофильтр ---
        ws.auto_filter.ref = f"A1:{openpyxl.utils.get_column_letter(last_col)}{last_row}"

    buf.seek(0)
    return buf.getvalue()
```

1. Запустить `streamlit run app.py`
2. Вкладка «Сводка» → табы «По дисциплинам/разделам/комплектам»
3. Нажать «📥 Выгрузить в Excel»
4. Открыть файл — проверить:
   - Шапка с бледными цветами, чёрный текст, без эмодзи
   - Колонки C-H одинаковой ширины (12)
   - Колонка B с переносом строк
   - Автофильтр включён
   - Строка ИТОГО выделена серым фоном, жирный шрифт
